# CAPSTONE-ScanGo-A-Locker-System-for-Seamless-Digital-Access-and-Payment
ScaNGo is a smart locker system powered by Raspberry Pi 5, integrating solenoid locks, JavaFX-based UI, and QR-based cashless payments (GCash/PayMaya). It enables students to securely access lockers, view real-time status, and enjoy automated data management for a seamless digital experience.
